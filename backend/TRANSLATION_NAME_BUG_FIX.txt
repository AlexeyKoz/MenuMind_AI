TRANSLATION NAME BUG FIX
========================

PROBLEM:
Russian and Hebrew recipe names show INGREDIENT names instead of recipe names!
Example: "небольшой пучок листьев базилика" (small bunch of basil) instead of "Пицца Маргарита"

ROOT CAUSE:
File: backend/apps/recipes/tasks.py
Function: translate_recipe_to_language()

Variable name collision:
- Line 364: translated_name = recipe name ("Pizza Margherita")
- Lines 399-459: Loop through ingredients, translated_name gets OVERWRITTEN with last ingredient name
- Line 517: translation.name = translated_name (NOW IT'S THE INGREDIENT NAME!)

BUG: translated_name variable was reused for both recipe name AND ingredient names!

FIX APPLIED:
1. Line 364: Changed to translated_recipe_name (unique variable)
2. Line 517: Changed to use translated_recipe_name instead of translated_name

Now:
- Recipe name stays in translated_recipe_name
- Ingredient names use translated_name (local to the loop)
- No collision!
