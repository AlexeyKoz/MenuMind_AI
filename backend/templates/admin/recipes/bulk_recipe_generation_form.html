🍳 Bulk Recipe Generation

This tool allows you to automatically generate multiple recipes from the internet. Enter recipe names (one per line) and the system will search, scrape, and create canonical recipes for each one.

💡 Tip: Each recipe will be searched on the internet, scraped, and added to your database. This process runs in the background, so you can close this page and check the job status later.

⚙️ How It Works:

  1. System searches for each recipe on the internet using DuckDuckGo
  2. Scrapes recipe content from the best matching website
  3. Uses AI to extract and structure ingredients and steps
  4. Maps ingredients to the IML database for translations
  5. Calculates nutrition information
  6. Creates a canonical recipe in your database
  7. Handles deduplication automatically

  • Duplicate recipes are automatically detected and skipped
